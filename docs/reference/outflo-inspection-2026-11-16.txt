## 1. Message writing with AI

3. The AI assisted tab has a card reading "OutFlo Agent also uses campaign context added by you", which links to the AI Campaign Context panel (see item 9).
4. Two collapsible sections show what the AI reads.
   - **Per profile** is "Live LinkedIn Fetch", with five ticked checkboxes: current role and company, recent posts, skills and endorsements, career transitions, shared interests.
   - **Per sender** is a read-only list: how the sender talks, complete profile information, previous messages in the chat, and the complete campaign sequence.

6. **Strategy** is a single-select row: Auto (default), Common ground, Value offer, Curiosity hook.
7. "AI Generation Instructions" is an optional free-text box. Below it are "Insert variable" buttons for First Name, Last Name and Company, plus a Variables dropdown.
8. A notice reads "You can still review every message in Preview before it sends." A "Using credits: 100" chip shows the balance. The preview button reads "Preview Message · 0.5 credits".
9. Message variables in the Variables dropdown:

11. Follow-ups use the same drawer. "Add Follow-up Message" adds a block with a Wait of 2 days (minimum 15 minutes), an "If not replied" chip, an empty message, and the same AI toggle. The first message waits 1 day after the connection is accepted (minimum 180 minutes).
